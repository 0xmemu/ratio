# Production Signoff Checklist

## Infrastructure
- Kubernetes deployment validated
- Autoscaling validated
- Network policies applied
- Health probes validated
- Backups validated

## Monitoring
- Prometheus active
- Alerts firing correctly
- Dashboards validated
- Sentry configured

## Execution Safety
- Validation pipeline tested
- Rollback flow tested
- Dry-run mode verified
- Approval workflow verified

## Wallet Operations
- Wallet isolation verified
- Emergency pause verified
- Gas limits verified
- Position limits verified

## Security
- Secrets rotation verified
- RPC failover verified
- Incident response reviewed
- Audit preparation completed

## Deployment
- Staging burn-in completed
- Mainnet limited rollout completed
- Observability validated
- Reliability tests completed
