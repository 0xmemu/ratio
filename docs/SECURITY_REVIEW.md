# Security Review Checklist

## Wallet Security
- Verify no secrets committed
- Verify environment separation
- Verify wallet rotation process

## RPC Security
- Verify provider redundancy
- Verify failover plan
- Verify rate limits

## Execution Controls
- Verify approval workflow
- Verify gas ceilings
- Verify rollback flow

## Infrastructure
- Verify backups
- Verify encrypted storage
- Verify restricted access

## Monitoring
- Verify alerts active
- Verify logging active
- Verify audit trails active
