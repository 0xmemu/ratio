# SRE Guide

## Core Objectives

- maximize uptime
- minimize execution failures
- maintain rollback safety
- maintain observability

## Golden Signals

Track:
- latency
- traffic
- errors
- saturation

## Reliability Practices

- staged rollouts
- rollback readiness
- chaos testing
- alert tuning
- postmortems

## Deployment Practices

- gradual rollout
- canary execution
- low-capital validation
- monitoring before scaling

## Incident Handling

- classify severity
- pause unsafe execution
- validate wallet safety
- restore services carefully
